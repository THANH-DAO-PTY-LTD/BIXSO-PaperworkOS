# Source and notices

Thanh Dao Pty Ltd releases this source under the MIT license in the repository root. The matter stages, decision types, document statuses and invoice rules follow the shared matter model originally developed for LawsFinder. For this release the rules were rewritten as plain functions without storage, accounts or legal content, and the command line, demo and tests were added. The examples use fictional people and businesses.

This release has no runtime dependencies beyond Node.js.
