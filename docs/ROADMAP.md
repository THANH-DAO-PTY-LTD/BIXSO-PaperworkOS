# BIXSO Paperwork OS roadmap

**Updated 28 November 2026.** Part of the [BIXSO OS roadmap](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/ROADMAP.md). This project is the open concept and lite code for the rules in [LawsFinder](https://lawsfinder.com).

## Now: in this repository

- A matter shared between a client and their professionals; the client decides
- Documents that move from needed to final only after review
- Versioned agreements and invoices that must match what was agreed

## Next: help wanted

- Print a matter's full timeline ([#4](https://github.com/THANH-DAO-PTY-LTD/BIXSO-Paperwork-OS/issues/4))
- Attach file references (not files) to documents
- Reminders for documents and invoices that are waiting

Pick one up, or comment on the issue before you start. Items without an issue are open for an idea or a pull request.

## Questions for people who do this work

- Which step in your matters doesn't fit?
- Who should be allowed to see an invoice, and when?

Answer in an issue using **Share an idea**, or on [r/BIXSO](https://www.reddit.com/r/BIXSO/).

## Not planned in this repository

- Legal, tax or financial content or advice; e-signatures; holding money.

This is a direction, not a promise of dates. How decisions are made: [GOVERNANCE](https://github.com/THANH-DAO-PTY-LTD/.github/blob/main/GOVERNANCE.md).
